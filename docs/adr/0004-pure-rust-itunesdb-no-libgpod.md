# Pure-Rust iTunesDB Parser, Serializer, and Signer (No libgpod)

PodLoader implements `iTunesDB` binary parsing, serialization, and `hash58`/`hash72` checksum generation in pure Rust rather than binding to the legacy C library `libgpod`. `libgpod` is unmaintained and pulls in heavy C dependencies (`glib`, `gobject`, `libxml2`, `gdk-pixbuf`) that complicate cross-platform builds on Windows and macOS; a pure-Rust implementation keeps builds reproducible, memory-safe, and directly testable against binary fixtures. For 2007+ iPods that require `hash58`/`hash72` signing, PodLoader reads the 8-byte FireWire GUID from the USB device serial descriptor via pure-Rust `nusb` when `iPod_Control/Device/SysInfo` is missing it, caches it into `SysInfo`, and provides a manual entry fallback.
