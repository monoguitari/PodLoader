# Pure-Rust Audio Decoding, Playback, and ALAC Encoding Pipeline

Audio transcoding and in-app preview playback use a pure-Rust pipeline (`symphonia` for decoding FLAC/OGG/WAV/MP3/AAC/ALAC, `rodio` for cross-platform audio output, and a pure-Rust ALAC `.m4a` encoder) as the default path, with optional fallback to a system `ffmpeg` binary for lossy AAC/MP3 encoding. For Ogg-encapsulated Opus audio, Symphonia's Ogg demuxer parses stream parameters, duration, and OpusTags metadata, routing to ALAC `.m4a` container generation. This guarantees consistent playback of ALAC and FLAC across macOS, Windows, and Linux without webview codec discrepancies, and supports the primary FLAC-to-ALAC iPod workflow out of the box without bundling an 80–100 MB FFmpeg binary sidecar in every installer.
